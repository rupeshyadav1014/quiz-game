Quiz Game

A simple and interactive quiz game built with HTML, CSS, and JavaScript.
Test your knowledge by answering multiple-choice questions and see your
score at the end.

Technologies Used

HTML5

CSS3

JavaScript

## Live Demo

[Play the Quiz Game](https://rupeshyadav1014.github.io/quiz-game/)

Features

Interactive quiz interface

Multiple-choice questions

Instant answer selection

Score tracking

Final score/result display

Responsive and simple user interface

Runs directly in the browser with no installation required

Project Structure

quiz-game/
├── index.html
├── style.css
└── script.js

How to Run Locally

Clone the repository.

Open the project folder in VS Code.

Open index.html in your browser.
